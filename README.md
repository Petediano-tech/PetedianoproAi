
# Petediano Pro - AI Creative Suite

This is a Next.js application built with Firebase Studio. It is an all-in-one AI-powered creative suite designed to help users with content creation, photo editing, and idea generation.

## Features

- **AI Photo Editor**: Enhance photos with automatic adjustments.
- **AI Picture Generator**: Create original images, logos, and wallpapers from text prompts.
- **AI Content Suite**: Generate stories, video scripts, blog posts, social media plans, and more.
- **PeteAI Assistant**: A friendly AI helper for brainstorming and app guidance.
- **Firebase Integration**: Secure user authentication and data storage.
- **PWA Ready**: Installable on mobile and desktop devices for an app-like experience.

## Tech Stack

- **Framework**: Next.js (App Router)
- **UI**: React, ShadCN UI, Tailwind CSS
- **AI**: Google Genkit (Gemini)
- **Backend**: Firebase (Authentication, Firestore, Storage)

To get started, explore the code in `src/app/`.
