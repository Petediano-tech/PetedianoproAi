# **App Name**: Petediano Pro

## Core Features:

- Account Management: User account creation and management with Google sign-in, email/password registration, profile picture upload, and account deletion confirmation.
- AI Photo Editor: AI-powered image enhancement with effects, text addition, background removal, brightness/contrast adjustment, blur, texture, color grading, blend, PIP, and overlay.
- AI Content Generation: Generative AI tool for original motivational, funny, and long-form story creation with associated illustrations and PDF conversion.
- AI File Analyzer: File analysis for uploaded media to describe and explain the content of the media.
- AI Picture Generator: Picture generator tool with wallpaper, logo, flyer, collage, and social media post creation, aspect ratio selection and custom text implementation using professional graphic design fonts.
- In-App Messaging: Free in-app texting utilizing existing device data or text plan; customizable with themes and wallpapers.
- PeteAI Assistant: AI-powered assistant that provides suggestions for various tasks using a tool connected to PeteAi.

## Style Guidelines:

- Primary color: Vibrant purple (#9C27B0) for a modern and creative feel.
- Background color: Light purple (#F3E5F5) for a soft, desaturated base.
- Accent color: Pink (#E91E63) to provide contrast to purple. This pink shade can act as a playful and eye-catching counterpoint to the app's overall aesthetic.
- Headline font: 'Belleza' sans-serif, for headers and emphasis; body font 'Alegreya' serif for longer text passages.
- Note: currently only Google Fonts are supported.
- Custom icons with a modern, minimalist style.
- Clean, professional layout emphasizing content discoverability, making it easy for users to navigate different types of generated media.
- Smooth transitions and animations for likes, dislikes, and feedback submission.
